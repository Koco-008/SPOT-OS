# Mitwirken

Der Stand `0.1.7` ist der BMA-Freeze. Verbesserungen und Änderungen nach diesem Zeitpunkt gehören nicht zur ursprünglichen BMA.

Pull Requests sollen je Änderung eine klare Beschreibung, passende Tests und eine nachvollziehbare Hardwarefreigabe enthalten, falls Treiber-, Kernel-, Touch- oder Bootverhalten betroffen ist.

Dieses Repository spiegelt **nicht automatisch** die Signierquelle des offiziellen Releasekanals. Eine Quelländerung in diesem Repository allein erzeugt **keine** neue, signierte OTA-Version. Für eine spätere Migration der geschützten Signierpipeline ist ein gesonderter, vollständig getesteter Freigabeprozess erforderlich.

Keinen privaten Signing-Key, keine Tokens, keine vollständigen Journale und keine echten Zugangsdaten einreichen.
